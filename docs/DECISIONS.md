## Engineering proposals to validate

These are provisional implementation choices, not user-approved measured facts:

- Working name/folder: Cardputer ADV Lofi / `cardputer-adv-lofi`.
- One built-in animated scene and three mood presets for the initial release.
- Produce source samples on the Mac in `assets/audio/`: local pitched-note synthesis plus bounded ElevenLabs effects auditions, as detailed in [Sample production](SAMPLE_PRODUCTION.md).
- 32 kHz mono PCM16, eight voices initially, 512-sample blocks; test 12 voices only with sufficient headroom.
- 12 FPS target and 6 FPS visual fallback; audio owns timing.
- Compact BIN target below `0x140000` bytes; compatibility determined by the supported profile and actual installed layout.
- Common reference PlatformIO/M5 library pins as the starting stack.
- Favorites/settings are RAM-only without SD; SD provides persistent saves. The seed can still be viewed/copied without SD.
- Simple static site generator with real preview frames, matched audio examples and canonical version/checksum data.
- English first; no multilingual release requirement has been requested.

## Questions for later evidence

- Which instrument engine is pleasant enough through both the small speaker and headphones?
- Does a useful embedded sample bank fit alongside one scene within the compact BIN goal?
- What heap, task/DMA usage and render time remain on the actual ADV?
- Is indexed M5GFX rendering a good fit, or is a bounded tile renderer preferable?
- Which installed M5Apps layout must the first physical release support?
- What battery runtime is achieved at the intended listening volume and brightness?

These questions require prototype measurements or later release context, not guesses during planning. They do not block the first local feasibility milestone.
